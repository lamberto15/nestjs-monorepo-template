# Security policy

## Supported versions

Only the latest release (the newest `v*` tag on `main`, see
[releases](docs/releases.md)) and `main` get security fixes. While the template
has no adopters, breaking changes are accepted between minor versions
([roadmap](docs/roadmap.md), "Early stage"), so an older release is not patched.

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub Security Advisories](https://github.com/lamberto15/nestjs-monorepo-template/security/advisories/new)
and include what you found, how to reproduce it, and the affected commit or
release.

The maintainer aims to acknowledge a report within 7 days and to say what
happens next (a fix, a release, or why it is not a vulnerability). Fixes are
published as a new release; the advisory credits you unless you ask otherwise.

Projects built from the template are not covered by this policy: report
problems in your own code to its owner.
